# Project Agent Rules & Guidelines

## File Size & Refactoring Rules

### Threshold Rule
* **Maximum File Length:** Any new or refactored file exceeding **256 lines of code (LOC)** must be refactored and split into multiple smaller, modular, and logical components/files.

### Feature Documentation
* **Documentation Rule:** Document all new or updated feature(s) in the `docs/feature-list.md` file (maintaining an organized list of all platform features under the appropriate section heading).
